                                          bp is held — and everyone deadlocks waiting on each other.

                                            The fix: replace breadnx with a non-blocking getblk(..., GETBLK_NOWAIT). In HAMMER2's COW model, writes always go to freshly allocated locations, so other columns in the same stripe will be zeros. If a block
